# فحص الامتثال الإعلاني

## متى تُستدعى
قبل نشر أي صفحة جديدة، أو عند إضافة/نقل موضع إعلان.

## نقاط الفحص
1. **كثافة الإعلانات**: لا إعلانات تحجب المحتوى الأساسي أو تجعل النقر بالخطأ سهلًا (Accidental Clicks).
2. **المحتوى المحيط**: لا إعلان مجاور مباشرة لمحتوى ديني حساس (نص قرآني/حديثي) — مسافة بصرية واضحة (دار القرآن/دار السنة تحديدًا).
3. **المحتوى المحظور**: لا محتوى للكبار، عنف صريح، كراهية، تحريض — فحص الصفحة كاملة قبل إضافة أي سكربت إعلاني عليها.
4. **سرعة التحميل**: سكربتات الإعلانات لا تُحمَّل بطريقة تعطّل Lighthouse < 90 (استخدم `async`/`defer` دائمًا).
5. **الشفافية**: صفحة "سياسة الخصوصية" تذكر استخدام الإعلانات وملفات تعريف الارتباط صراحة.

## Expected Output
تقرير Pass/Fail لكل نقطة أعلاه، مع توصية بموضع الإعلان الدقيق إن كان Fail بسبب الموضع لا المحتوى.
