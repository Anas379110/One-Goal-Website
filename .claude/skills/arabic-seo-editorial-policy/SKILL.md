# سياسة تحرير المحتوى العربي — anasnet.com

## متى تُستدعى
عند صياغة مسودة مقال جديد، أو مراجعة محتوى قبل تعبئة حقل `reviewedBy`.

## قواعد صارمة (غير قابلة للتفاوض)
- **منع النسخ الحرفي**: أي فقرة تُعاد صياغتها بالكامل بكلمات المحرر، لا نسخ من المصدر.
- **توثيق المصادر إلزامي**: حقل `sources` لا يُترك فارغًا أبدًا.
- **للمحتوى السياسي/الحساس (Khabr تحديدًا)**: مصدران متقاطعان على الأقل، وإلا يُنشر بوسم "غير مؤكد — مصدر واحد" صراحة.

## بنية المقال القياسية
1. عنوان جذاب دقيق (لا Clickbait مضلل).
2. مقدمة (2-3 جمل) تلخّص الفكرة.
3. محتوى مقسّم بعناوين فرعية (H2/H3) لا فقرة واحدة طويلة.
4. خاتمة أو خلاصة قصيرة.
5. `excerpt` بحد أقصى 160 حرفًا (Meta Description).

## خطوات المراجعة قبل approved
1. تحقق: هل الفقرات معاد صياغتها فعليًا لا منسوخة؟
2. تحقق: `sources` مملوءة وروابطها تعمل فعليًا؟
3. تحقق: لا محتوى للكبار/عنف/كراهية (سياسات AdSense/Adsterra/Monetag/Zeydoo).
4. تحقق: العنوان يطابق المحتوى الفعلي (لا تضليل).

## Expected Output
تقرير: ✅ جاهز للنشر / ⚠️ يحتاج تعديل + قائمة النقاط بالتحديد.
