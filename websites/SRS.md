# SRS.md — One goal (موقع محتوى رياضي)

## Functional Requirements
- FR1: عرض مقالات مصنّفة (ملخصات مباريات / أخبار أندية / تحليلات).
- FR2: صفحة تصنيف لكل فئة محتوى مع Pagination.
- FR3: بحث نصي داخل الموقع (Pagefind).
- FR4: صفحة مقال فردية بروابط "مقالات ذات صلة".
- FR5: عرض المصدر/التاريخ لكل مقال.
- FR6: صفحات ثابتة: من نحن، اتصل بنا، سياسة الخصوصية، شروط الاستخدام.
- FR7: دمج سكربتات AdSense/Adsterra/Monetag/Zeydoo.

## Non-Functional Requirements
- Performance: First Load < 3s، Lighthouse > 90.
- Accessibility: WCAG 2.1 AA.
- Localization: عربي RTL كامل. نطاق المحتوى: دوري عربي عام + دوري أوروبي عام (مؤكَّد).

## User Stories
US1: كزائر، أريد تصفح آخر أخبار الأندية مصنّفة، حتى أتابع فريقي دون تشتت.
AC: صفحة تصنيف تعرض أحدث 10 مقالات + Pagination، تاريخ/مصدر واضحان، تحميل < 3s.

US2: كزائر يبحث عن نتيجة مباراة، أريد بحثًا نصيًا سريعًا، حتى أصل للمعلومة مباشرة.
AC: نتائج خلال ثانية (Client-side)، البحث يشمل العنوان والمحتوى.

## Use Case — قراءة مقال
Actor: زائر | Trigger: نقر رابط مقال | Main Flow: تحميل → عرض المحتوى+المصدر+التاريخ → مقالات ذات صلة | Error Flow: مقال غير موجود → 404 عربي.
